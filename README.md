# IKAS Marketplace (Public)

Public skill marketplace for [IKAS Workspace Manager](https://github.com/tarotme/ikas-workspace).

## Structure

```
skills/
├── <skill-name>/
│   ├── SKILL.md
│   └── scripts/
│       └── ...
```

Each skill is a self-contained directory under `skills/`, containing:

- **SKILL.md** — Skill definition (description, instructions, parameters)
- **scripts/** — Scripts used by the skill
